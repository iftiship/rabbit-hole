# 🐇 Rabbit Hole — Interactive Visual Knowledge Explorer

> **Explore. Connect. Discover.**  
> An interactive visual knowledge graph explorer inspired by intellectual rabbit holes. Enter any question, navigate concept networks, examine evidence-backed sources, and discover **Weird Bridges** across distant disciplines.

## ✨ Features
- **Dynamic Interactive Knowledge Graph**: Visualized using Cytoscape.js with concentric orbits, smooth curves, and glowing core focal nodes.
- **Deep Concept Inspection**: Right-hand panel displaying rich overviews, topic tags, key connections, hero photography, and verified sources.
- **⚡ Weird Bridges (Signature Feature)**: Surprising, cross-disciplinary connections labeled with evidence indicators (*Evidence-supported*, *Speculative*, *Analogy*).
- **Gemini AI + Tavily Research Grounding**: Live synthesis and factual grounding.
